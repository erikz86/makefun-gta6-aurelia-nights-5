Aurelia Nights V is an offline 2D top-down open-world crime game set in a stormy coastal city. Walk, steal and drive cars, recruit a crew, run properties, fight guards, and lose the police while four story chapters unfold.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080. Everything is local and the soundtrack is synthesized with WebAudio.
